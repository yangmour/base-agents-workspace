# 前端后台重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变后台现有页面入口和 API 契约的前提下，把 `base-admin-web` 的路由、请求、用户启动态、布局和系统管理页面拆成可测试、可维护的边界。

**Architecture:** 第一阶段不做视觉大改，不迁移 `weixin-bot-admin`，只拆 `base-admin-web` 的核心链路。`router/index.ts`、`utils/request.ts`、`stores/user.ts` 保留 facade 入口，内部委托到小模块；页面先抽组合式函数和子组件，再保持原路由路径不变。

**Tech Stack:** Vue 3、TypeScript、Vite、Vue Router、Pinia、Axios、Element Plus、Vitest、vue-tsc。

## Global Constraints

- 文件路径只记录仓库内相对路径。
- 每完成一个任务提交一次。
- 生产代码变更前必须先写失败测试并确认失败。
- 不改变 `base-admin-web/src/api/**` 的 public function 名称。
- 不改变现有路由 path、route name、菜单权限语义。
- 不做 UI 视觉大改；只做结构拆分、类型收敛和可测试性补强。
- 每次提交前至少运行该任务聚焦测试；影响核心链路时同时运行 `npm run type-check` 和 `npm run build`。
