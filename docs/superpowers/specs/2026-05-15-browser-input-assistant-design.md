## 1. 背景与目标

用户在浏览器输入框中经常需要输入来自剪贴板的文本，例如手机号、验证码、姓名、地址、长文本等。直接粘贴可能无法触发某些页面的输入流程，或不符合用户希望的“逐字输入”体验。

本项目提供一个浏览器扩展，在用户主动触发后读取剪贴板纯文本，并以拟真输入或兼容输入方式写入当前网页中的目标输入区域。

目标：

- 支持任意剪贴板纯文本输入。
- 默认使用拟真输入模式。
- 支持切换到兼容输入模式。
- 支持快捷键、插件按钮、右键菜单、选择输入位置等多种入口。
- 支持长文本确认、进度展示、暂停、继续、取消。
- 默认不保存剪贴板历史，不联网，不上传内容。

## 2. 范围

### 2.1 本期范围

- 独立新建 `browser-input-assistant/` 模块。
- 使用 WXT、Vue 3、TypeScript 开发浏览器扩展。
- 支持 Chrome、Edge、360 浏览器、Firefox 手动加载使用。
- 支持读取剪贴板文本并输入到：
  - `input`
  - `textarea`
  - `contenteditable`
  - 常见 Vue / React 控制输入框
- 支持四类触发入口：
  - 快捷键
  - 插件 popup 按钮
  - 右键菜单
  - 页面选择输入位置模式
- 支持两种输入模式：
  - 拟真模式
  - 兼容模式
- 支持速度配置：
  - 默认随机速度
  - 快 / 中 / 慢分档
  - 高级自定义延迟
- 支持配置本地保存、导入、导出。
- 支持可选调试日志。

### 2.2 暂不纳入本期范围

- 不做后台自动监听剪贴板。
- 不做剪贴板历史管理。
- 不上传任何文本或日志到远程服务。
- 不做账号体系。
- 不做云端配置同步作为强依赖。
- 不保证绕过任何网站风控或自动化检测。

| 项目 | 选择 | 状态 |
| --- | --- | --- |
| 扩展框架 | WXT | 待完成 |
| 语言 | TypeScript | 待完成 |

| 样式 | 原生 CSS / 轻量 CSS | 待完成 |

选择理由：

- WXT 适合多浏览器扩展开发，能管理 manifest、background、content script、popup、options 等入口。
- TypeScript 便于维护输入任务状态、配置结构、日志结构和跨浏览器 API 类型。
- Vue 3 与当前仓库前端技术栈一致，适合开发 popup 和 options 页面。
- webextension-polyfill 提供 Promise 风格 API，降低 Chrome 与 Firefox API 差异。

## 6. 输入目标定位

目标定位按优先级执行：

1. 当前聚焦元素。
2. 当前页面中最近一次记录的可输入元素。
3. 用户主动进入“选择输入位置模式”后点选的元素。

支持元素：

- `input`
- `textarea`
- `contenteditable="true"`
- 可编辑富文本区域

无可用目标时：

- 弹出提示：“请先点击输入位置”。
- 提供“选择输入位置”入口。

状态：待完成。

## 7. 输入模式设计

### 7.1 拟真模式

默认模式。

行为：

- 按字符逐个输入。
- 字符之间使用随机延迟。
- 默认延迟范围：50ms - 160ms。
- 对换行、段落使用额外停顿。
- 尽可能触发 keydown、beforeinput、input、keyup 等事件。
- 同步更新真实 DOM 值或可编辑区域内容。

状态：待完成。

### 7.2 兼容模式

备用模式。

行为：

- 逐步更新目标元素内容。
- 触发标准 input / change 事件。
- 不强调键盘事件拟真。
- 优先保证 Vue / React 等受控输入框能感知变化。

状态：待完成。

### 7.3 模式切换

- popup 中提供明显的模式切换按钮。
- options 中可设置默认模式。
- 快捷键、右键菜单、插件按钮都使用当前选中模式。

状态：待完成。

## 12. 权限设计

建议权限：

```json
{
  "permissions": [
    "storage",
    "contextMenus",
    "activeTab",
    "scripting",
    "clipboardRead"
  ],
  "host_permissions": ["<all_urls>"]
}
```

权限说明：

- `storage`：保存用户配置和本地日志。
- `contextMenus`：提供右键菜单入口。
- `activeTab`：对当前活动页面执行输入。
- `scripting`：注入或执行必要脚本。
- `clipboardRead`：在用户主动触发时读取剪贴板文本。
- `<all_urls>`：允许在不同网站输入，但不主动采集页面数据。

状态：待完成。

## 17. 验收标准

- 插件可以在目标浏览器中手动加载。
- 用户可以通过快捷键、popup、右键菜单、选择模式触发输入。
- 插件默认以拟真模式输入剪贴板文本。
- 用户可以切换到兼容模式。
- 长文本输入前有确认。
- 输入过程中可以暂停、继续、取消。
- Esc 可以取消输入。
- 配置可以保存、导出、导入。
- 默认不记录输入内容。
- 完整调试日志开启前有明确风险提示。
- 不联网、不上传、不后台监听剪贴板。
