# 文件管理统计、详情与搜索设计

状态：用户已批准，实施及部署已完成；现有文件和逻辑删除历史记录保持不变。

## 已确认的问题

文件统计的自定义 SQL 仅按租户和模块过滤，未排除状态为 0 的已逻辑删除记录。列表根据状态过滤，默认仅查询正常文件，因此统计与列表采用不同口径。截图选择“处理中”，列表为空本身并不代表分页故障。

现有文件信息 DTO 缺少对象路径、存储桶、存储提供者等字段，管理端也没有独立的文件详情接口。页面只有模块与状态筛选。

## 推荐行为

顶部显示“当前查询共 N 个文件，大小 S；今日新增 M 个”，统计和分页使用完全相同的租户、模块及搜索条件；统计不受页码影响。“今日”按北京时间的自然日计算。

默认查询正常与处理中的有效记录，排除状态 0 或已逻辑删除的记录。状态可筛选正常或处理中。保留所有历史记录，沿用现有逻辑删除流程。

备选方案：同时显示模块有效文件总量和当前查询结果，明确两种口径。推荐只显示当前查询统计，使筛选后的数字与分页总数一致。

## 搜索与分页

- 关键词：对原始文件名及对象路径进行模糊匹配。
- 文件路径：独立输入框，可与关键词组合，对逻辑对象键与已记录的实际存储路径进行模糊匹配。
- 上传日期：起止日期范围，包含所选结束日期；转换为北京时间开始日期零点至结束日期次日零点的半开区间。
- 文件类型：图片、视频、音频、文档、其他；按 MIME 分类，兼容媒体类型为空的历史记录。允许输入 MIME 类型进一步匹配。
- 状态：全部有效文件、正常、处理中。
- 条件之间取交集；点击查询或重置时回到第一页。重置保留当前模块，清空其余搜索条件。

搜索通过服务端查询实现，分页和统计都在同一查询范围内执行，不在浏览器对当前页做过滤。字符串长度、页码、页大小、状态和日期范围均在服务端校验。模糊查询使用绑定参数，百分号、下划线等作为普通字符处理。

## 列表与详情

列表显示文件名、对象路径、文件类型、大小、状态及上传时间。新增详情按钮，在独立抽屉中显示：

- 文件键、模块、原始文件名、大小、MIME 类型、媒体类型、状态及处理状态。
- 存储提供者、存储桶、逻辑对象路径和已记录的实际存储路径。
- 访问权限、文件哈希、上传者、业务类型与业务关联 ID。
- 创建时间、更新时间，以及已有业务元数据。

历史记录没有保存的信息显示“—”，不伪造路径或哈希。详情不返回上传回调令牌、签名密钥、上传会话标识或临时写入 URL。

处理中的文件允许查看元数据；只有正常文件可下载。下载链接仍由现有下载权限和接口按需生成。详情接口使用文件查看权限，并限定可信租户与所选模块，不放宽现有已发布文件查询接口。

## 实现边界

后端在 file 服务查询层复用搜索条件构造逻辑；自定义聚合 SQL 增加同样的过滤条件。admin 服务将经过验证的搜索参数转发给 file 服务，租户和操作者仍来自认证上下文。新增独立的元数据详情查询，保留现有业务文件查询行为及 Feign 超时配置。

前端保存输入条件及已提交条件，查询、重置与模块切换统一管理分页。取消旧请求，并忽略过期响应，避免旧模块或旧条件的数据覆盖新结果。部分请求失败时明确显示错误，不将旧统计与新列表混在一起。

本次不新增环境变量或调整存储配置，不修改上传发布、删除、配额与模块删除流程。

## 验证

后端通过实际 MySQL 查询验证逻辑删除排除、租户和模块隔离、组合筛选、日期边界、字面量模糊搜索及统计与分页总数一致；验证处理中文件详情可读，而原有下载查询仍拒绝处理中的文件。管理端测试验证权限、参数传递及无效输入。

前端测试验证查询与重置回到第一页、列表与统计条件一致、详情字段展示及旧响应不覆盖新结果；运行 type-check 和生产构建。线上验证优先只读检查现有数据，不删除现有视频或模块。
