# 文件管理桶名与全部范围

本次按用户“桶名默认全部，下面的数据字段带着桶名”的要求实施。默认当前租户全部模块和桶的有效文件；模块、桶名为独立可选筛选。桶名下拉候选来自当前租户有效文件持久化的 bucket_name，去重排序，不依赖当前页或模块现配置。列表增加桶名列，缺失值显示 —。

搜索与统计使用相同 bucketName 精确过滤，并继续使用 status IN (1,2)、id_delete=0 及可信租户。详情和写操作依然要求行内具体模块；全部模式允许操作当前结果中的行，不允许旧查询的行操作。详情按行内模块请求。上传仍需选定模块。查询、重置、切换取消旧请求，旧响应不能覆盖新数据。

保留现有内部模块查询接口，增加跨模块只读搜索及统计路由。不得改动真实文件、模块、逻辑删除历史、Nacos 或 YAML。使用真实 MySQL、HTTP/Feign 契约和前端生命周期测试核对。
