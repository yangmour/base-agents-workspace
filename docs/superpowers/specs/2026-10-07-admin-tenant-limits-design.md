# G1 租户账号配额与有效期

继续用户已授权的 G1 收口，复用租户编辑弹窗、RI、后台独立认证及幂等事务。

本切片新增租户级 `maxUsers`：null 表示不限额，正整数范围1–1,000,000。数量为该租户未删除的后台账号，停用账号和初始管理员也计入。用户删除后释放名额，重复幂等写入不重复占用；不得把列表的数据权限范围当作配额统计范围。平台管理员可配置/清空配额，低于现有账号数返回422，既有租户默认不限额。文件存储配额留在文件域G2。

采用真实账号数与数据库租户行锁，避免持久计数器与已有初始化工具漂移，也避免跨Pod进程内锁。新增先完成数据范围/参数检查和密码编码，再锁定可信租户；配额计数使用覆盖索引与当前锁定读，避免幂等外层可重复读事务的旧快照超卖。租户编辑保留套餐行→租户行锁顺序；配额校验、用户插入及幂等回执在同一事务。不限额也协调租户行，以防同时启用配额时遗漏在途新增。SQL当前读语义参考 [MySQL锁定读](https://dev.mysql.com/doc/refman/8.0/en/innodb-locking-reads.html)。用户删除在关系及用户写入前取得同一租户锁，防止计数覆盖索引锁与用户主键锁形成环；不把此验收等同于容量压测。

有效期沿用数据库CURRENT_DATE：到期日当天有效，次日失效，null不限期。登录、刷新和受保护请求都执行数据库当前状态。平台停用/删除租户，以及把有效期改为已过期或从已过期续期时，在同一事务撤销租户旧会话；续期需要重新登录，不能复活过期前的令牌。自然跨日过期即使没有后台任务也由鉴权拒绝，续期时会撤销旧会话。登录密码编码在锁外计算，提交会话前共享锁当前读租户有效性，再锁用户复核状态及凭证版本，与平台租户变更协调租户→用户→会话顺序。套餐状态与菜单规则保持既有行为。

前端原租户表单新增账号上限输入，原列表增加到期日/账号上限列；空值显示不限额/不限期。租户启停提交携带现有配额，避免默认清空。用户创建达到配额和租户缩减上限都返回RI/HTTP422及明确中文反馈，保留编辑内容。

验收包含失败先行测试、真实MySQL旧快照/并发新增/缩减/回滚/删除与索引检查、完整admin reactor package、前端类型与构建。独立测试租户上的双实例HTTP重复两轮，跨Pod竞争最后名额、幂等、外租户与限定范围不能绕过总量、到期日当天/昨天/清空/续期旧会话矩阵；真实浏览器配置配额、用户创建拒绝、调整后成功。登记资源、精确清理、注销自身会话和脱敏证据，分仓库独立提交。
